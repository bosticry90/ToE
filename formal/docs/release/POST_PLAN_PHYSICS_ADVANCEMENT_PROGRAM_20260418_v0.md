## Advancement contract

Advancement counts only when at least one of the following becomes true on canonical live surfaces:
1. A theorem-gap row changes class, closes, or otherwise improves on the live completion matrix and blocker dashboard.
2. A seam-integration-gap row improves its executable-path class, review state, or blocker burden on the seam normalization report and seam SLA ledger.
3. The master-action stack changes from support-only nonmoving status to a blocker-moving role after upstream pillar or seam evidence changes and one bounded recompute confirms that change.

The following do not count as advancement by themselves:
1. bounded maturity or bounded promotion labels.
2. non-claim package completion.
3. mirror-only or historical surface maintenance.
4. additional master-action packaging without changed upstream row truth.
5. material cascade confirmation alone when the live row and seam route classes remain unchanged.

## Decisions

- Included scope: blocker-moving pillar work, seam-path advancement, and bounded master-action re-evaluation after upstream movement.
- Included scope: explicit routing constraints for COSMO-SR, QM-STAT, QFT-GR, GR row 001, and the master-action stack.
