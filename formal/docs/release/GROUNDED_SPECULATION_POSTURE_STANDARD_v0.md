# Grounded Speculation Posture Standard v0

Spec ID:
- `GROUNDED_SPECULATION_POSTURE_STANDARD_v0`

Classification:
- `P-POLICY`

Purpose:
- Define repo-safe wording for grounded legitimate speculation.
- Separate bounded computational and design exploration from external-truth claims.
- Preserve fail-closed dormancy and restart semantics while allowing disciplined auxiliary analysis.

Scope:
- repository-local model-conditioned exploration only.
- applies to bounded computational-analysis outputs, design notes, and discriminator-planning surfaces.
- does not authorize active lane reopen, new packet execution, or restart trigger satisfaction.

Required posture tokens:
- `GROUNDED_SPECULATION_POSTURE_STATUS_v0: ACTIVE_NONLIVE_NONCLAIM`
- `GROUNDED_SPECULATION_POSTURE_RULE_v0: GROUNDED_SPECULATION_IS_MODEL_CONDITIONED_BOUNDED_AND_FALSIFIABLE_NOT_A_REALITY_CLAIM`
- `GROUNDED_SPECULATION_POSTURE_ALLOWED_OUTPUTS_v0: RETAIN_PRUNE_INCONCLUSIVE_RANKING_SENSITIVITY_AND_COMPARATOR_DESIGN_ONLY`
- `GROUNDED_SPECULATION_POSTURE_PROHIBITED_OUTPUTS_v0: NO_EXTERNAL_TRUTH_CLAIM_NO_LANE_REOPEN_NO_PACKET_AUTHORIZATION_NO_BLOCKER_MOVEMENT_CLAIM`
- `GROUNDED_SPECULATION_POSTURE_COMPUTATIONAL_ANALYSIS_BINDING_v0: AUXILIARY_NONCLAIM_COMPUTATIONAL_ANALYSIS_MUST_STAY_WITHIN_DECLARED_BOUNDED_AUTHORIZATION_CLASS`

Interpretation rules:
- Grounded speculation may state what a bounded model suggests, stresses, ranks, or fails to distinguish.
- Grounded speculation may not state that the repository has shown what reality is.
- Grounded speculation may support candidate retention, pruning pressure, comparator design, or sensitivity triage.
- Grounded speculation must remain bounded by declared observables, declared regimes, and explicit fail-closed outputs.

Allowed summary forms:
- bounded model retains candidate under declared assumptions.
- bounded scan increases pressure on one seam or regime limit.
- bounded computational-analysis result is inconclusive.
- bounded comparator design is now explicit enough for later empirical or policy review.

Disallowed summary forms:
- model proves reality.
- scan reopens dormant lane.
- auxiliary computation moves blocker by itself.
- bounded analysis authorizes restart or live execution.

- This standard permits disciplined speculation about bounded model behavior.
- This standard does not promote theorem status, empirical adequacy, or external-truth claims.
