## Completion contract

Objective-quality physics completion is earned only when every in-scope route is classified into one of these states on canonical live surfaces:
1. blocker reduced or row advanced.
2. blocker rerouted once with explicit stronger next-step evidence.
3. explicitly exhausted under the current architecture.
4. authority-blocked with current machine-checkable evidence.
5. externally held with current machine-checkable evidence.

The following do not count as completion by themselves:
1. bounded maturity or bounded promotion labels.
2. non-claim package completion without blocker movement or route termination.
3. mirror-only maintenance.
4. master-action packaging without changed upstream row truth.
5. leaving a row in a merely nonmoving state without an exhaustion or hold decision.

## Phase structure

### Phase 0: Completion contract opening

Scope:
1. Pin the completion-grade program surface.
2. Preserve the held post-plan advancement stack as the upstream measurement layer.
3. Convert next execution to closure-plus-exhaustion routing.

Exit criteria:
- Completion-grade program is mirrored into compact state, roadmap, and inventory.
- Completion queue declaration and report are pinned.
- Current seam and master-action constraints remain explicit.

### Phase 1: Completion queue materialization

Scope:
1. Materialize one ranked theorem-gap completion queue from the target map, theorem-gap trend, linkage registry, seam normalization, and program-state conversion review.
2. Exclude rows already exhausted under the current no-loop regime.
3. Promote one light theorem-gap row first, one clean second row next, and one heavy structural row after that.

Exit criteria:
- `ROW-PILLAR-QM-001` is excluded from immediate reuse.
- `ROW-PILLAR-COSMO-001` is first active row.
- `ROW-PILLAR-STAT-001` is second active row.
- `ROW-PILLAR-GR-001` remains queued as the first heavy structural dormant-package tranche.

### Phase 2: Single-row theorem-gap completion execution

Scope:
1. Execute one theorem-gap row at a time under a closeout contract that allows only blocker movement, blocker narrowing with one reroute, explicit exhaustion, or evidence repair.
2. Keep seams and master action subordinate to changed row truth.

Exit criteria:
- Every opened row ends in a machine-checkable closeout state.
- No same-row loop is reopened without changed blocker evidence.

### Phase 3: Conditional seam and master-action closeout

Scope:
1. Reassess seams only after row truth changes.
2. Spend the bounded master-action reevaluation only if upstream movement appears.
3. Freeze support-only routes explicitly when no upstream movement appears.

Exit criteria:
- No seam or master-action route remains implicitly pending.
- Every non-advanced route is either explicitly held, blocked, or exhausted.
