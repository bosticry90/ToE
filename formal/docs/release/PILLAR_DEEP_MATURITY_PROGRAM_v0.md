## Tier Model (M1-M5)

Definitions:
- `M1_THEOREM_CLOSED`: bounded theorem-chain closure under explicit assumptions.
- `M2_DERIVATION_COMPLETE`: derivation completeness gate closure (analytic completeness, canonical equivalence, assumption minimization, literature alignment).
- `M3_EMPIRICALLY_DISCRIMINATIVE`: at least one bounded discriminator lane that can eliminate alternatives.
- `M4_CROSS_PILLAR_INEVITABLE`: seam-level compatibility and counterfactual closure across pillars under minimized assumptions.
- `M5_THEORY_PARITY_LINKED`: bounded parity-link closure between mature pillar derivations and canonical theory-facing control surfaces.

Rule:
- A pillar may be considered deep-mature only when M1-M5 are all complete in bounded scope.
- Matrix `CLOSED` is necessary but not sufficient for deep maturity.
