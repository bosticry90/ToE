# ToE v0.1-alpha Release Standard v0

Spec ID:
- `TOE_V01_ALPHA_RELEASE_STANDARD_v0`

Classification:
- `P-POLICY`

Result token:
- `TOE_V01_ALPHA_RELEASE_STANDARD_PREPARED_FULL_PILLAR_SEAM_SCOPE`

Purpose:
- Prepare a criticizability standard for a full-pillar/full-seam v0.1-alpha candidate framework release.
- Require release-facing claims to carry claim labels, evidence pointers, assumptions/blockers, nonclaim IDs, and next-work status.
- Make full-pillar/full-seam coverage mean classified and evidenced, not solved.

Release claim definition:
- A release claim is any claim appearing in a v0.1-alpha release artifact, claim ledger, equation ledger, blocker ledger, pillar/seam coverage ledger, Lean dependency audit, or current release-facing public summary section.
- Historical and archived surfaces may retain legacy labels when their machine-readable context is not release-facing.
