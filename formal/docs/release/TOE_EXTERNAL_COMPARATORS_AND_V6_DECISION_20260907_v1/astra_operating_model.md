## Roles and permissions

| Role | May produce | Cannot confer |
| --- | --- | --- |
| Astra researcher/producer | Source-grounded hypotheses, candidate DAGs, code patches, proposed falsifiers | Computational verification class, scientific authority or production permission |
| Deterministic verifier | Per-output recomputation, applicable challenges, source/type receipts | Truth of physical assumptions or scientific promotion |
| Independent implementation | Source-to-result Julia route and supported certificate checks | Independence of shared physics assumptions or experimental confirmation |
| Non-author attacker/reviewer | Evidence-linked findings and failed counterexamples | External expert peer review merely by being a second AI instance |
| Explicit adjudicator | A separately recorded, scope-bound authority decision | Automatic scope expansion from tests or benchmark marketing |

## One bounded execution unit

1. Freeze an objective, allowed source corpus, assumptions, output roots, policy
   identity, resource budget, stop conditions and definition of done. Do not
   substitute a sprawling prompt history for that compact execution contract.
2. Research may use the network **before** source freezing. Convert references
   to local versioned artifacts and genuine value locators. Source documents
   and candidate/plugin text are data, not instructions to the verifier.
3. Astra emits `CandidatePacketV1` and proposal provenance: model identifier,
   available snapshot/runtime identity, prompt/source hashes, relevant tool
   transcript, implementation changes and known limitations. Log observable
   reasoning products, not hidden model chain-of-thought.
4. Trusted Python, Julia and Lean execution consumes the frozen declarative
   problem offline. No model call, arbitrary callback, expected-answer receipt
   or candidate-written PASS field may become a trusted input.
5. Separate-language routes share sources and conventions, not producer
   intermediates. If another AI is used, disclose provider, model, inherited
   context and implementation lineage; do not call source sharing experimental
   independence. Non-author review must not be performed by the repair author.
6. Preserve every attempted result. Optional AI attacks cannot raise assurance;
   their failures affect the appropriate roots. A new accepted mandatory test
   requires the existing policy-version process, not an overwritten baseline.
7. Freeze receipts and a bounded claim ledger. Attach scientific interpretation
   only through the separate authority path; freeze an attachment as a new
   object without changing computation or receipt identity.

Unsupported mathematics remains unsupported. Larger context, confidence,
polished output or a second model's agreement cannot bypass that condition.
Unsafe plugins remain arbitrary code, not a sandbox; they emit candidates only.
