## Three statement classes

Every statement entering the future analysis must receive exactly one initial
classification.

### Accepted project requirement

An existing accepted authority binds the statement. The statement may still
be only an evaluation-envelope assumption, recovery obligation, or external
policy; acceptance does not imply that it uniquely selects an action.

### Supplied standard-physics assumption

The statement is familiar or useful in standard GR but has not been derived or
independently selected as a native project principle. It may be used only in a
separately labeled conditional branch.

Examples include, unless separately authorized:

- at-most-second-order metric field equations;
- a fully adopted Einstein equivalence principle;
- Levi-Civita connection uniqueness;
- absence of additional propagating gravitational modes.

### New proposed postulate

The statement would add scientific content not already licensed by authority.
It cannot enter this packet's accepted-premise set and requires a separate
theory-selection decision.

No statement may move between these classes because it is convenient or
because it produces a familiar answer.

## Standard-GR isolation

The Einstein–Hilbert family is a comparison oracle only.

The permitted direction is:

```text
accepted requirements
-> computed survivor or equivalence class
-> comparison with F_EH
```

The forbidden direction is:

```text
F_EH supplied first
-> requirements reconstructed from F_EH
-> F_EH declared uniquely selected
```

Showing that `F_EH` satisfies the requirements is not a uniqueness proof.
Neither the Einstein equation nor its coefficients may enter as intermediate
selection premises.

## Equivalence rules

Two representatives may be placed in one local-bulk equivalence class only
when the packet records the applicable proof and all frozen domains agree.

Allowed equivalences include:

- algebraic tensor identities;
- total divergences whose variations vanish under the frozen compact-support
  local bulk contract;
- a four-dimensional topological density with no local bulk metric variation
  under the frozen conditions;
- an invertible local field redefinition only when it preserves domain,
  degrees of freedom, source coupling, observables, and boundary scope;
- normalization conventions only when the full coupled action and source
  normalization are transformed consistently.

The following are not silently equivalent:

- different operator or derivative order;
- different propagating degrees of freedom;
- local and nonlocal dynamics;
- metric-only and independent-connection theories;
- changes in source coupling;
- coefficients that change observables;
- sign, index, or boundary-condition changes.

Equivalence is limited to the declared local bulk scope. It does not establish
equality of global charges, boundary observables, or quantum theories.

## Distinctiveness criterion

A requirement counts as a strong project-specific gravitational principle only
if accepted authority gives it demonstrated action-selection power beyond
generic standard assumptions by at least one of:

- eliminating an otherwise viable inequivalent family;
- fixing a coupling or coefficient;
- linking gravity to another accepted pillar through a derived relation;
- explaining why an Einstein–Hilbert-type limit emerges;
- requiring a new invariant;
- producing a distinctive observable;
- proving a falsifiable no-go result.

Repository ownership, terminology, or methodological usefulness alone is not
distinctiveness.

## Exact decision order

Independent analysis must apply these gates in order.

### Gate 1 — consistency

If no family in the frozen envelope satisfies all accepted requirements, return:

```text
REQUIREMENT_SET_INCONSISTENT
```

This requires an explicit inconsistent subset or proof that the survivor set is
empty. An incomplete catalog alone is not sufficient.

### Gate 2 — minimal-class distinctiveness no-go

If consistent families exist, but a proof shows that the desired project-
specific gravitational behavior cannot occur under the frozen metric-only,
local assumptions, return:

```text
NO_GO_UNDER_MINIMAL_METRIC_LOCAL_ASSUMPTIONS
```

This is not logical inconsistency; the minimal class remains viable but cannot
supply the required distinctiveness.

### Gate 3 — unique native selection

If accepted project-native requirements reduce the envelope to one physical
family or tightly bounded equivalence class without supplied uniqueness
assumptions, return:

```text
NATIVE_PRINCIPLE_SET_SELECTS_ACTION_FAMILY
```

Any remaining coefficient freedom must be stated.

### Gate 4 — standard-GR collapse

If the uniquely surviving equivalence class is Einstein–Hilbert-type and no
project-specific dynamics remains, return:

```text
CURRENT_REQUIREMENTS_COLLAPSE_TO_STANDARD_GR
```

The result must identify every assumption required for collapse and separate
native accepted requirements from supplied standard-GR assumptions. A collapse
that requires a supplied second-order assumption is conditional, not native.

### Gate 5 — ordinary underdetermination

If multiple inequivalent families survive and the record does not prove that
all refinements of accepted principles are exhausted, return:

```text
ACTION_FAMILY_UNDERDETERMINED
```

This is the conservative multiple-survivor result.

### Gate 6 — new postulate logically required

Return:

```text
DISTINCTIVE_GRAVITATIONAL_POSTULATE_REQUIRED
```

only if the analysis both:

1. exhausts the demonstrated selection power of every accepted current
   principle; and
2. proves, using surviving inequivalent countermodels or an equivalent
   argument, that no refinement using only those accepted premises can select
   among the survivors.

This proof burden keeps Gate 6 distinct from ordinary underdetermination.

Exactly one result is permitted.
