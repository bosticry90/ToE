## 4. Provenance classifier

Any future gravitational proposal must receive exactly one initial provenance
class before its formula is evaluated.

### `DERIVED_FROM_PROJECT_PRINCIPLE`

Required:

- a byte-bound project principle predating the proposed action formula;
- an explicit derivation that restricts the allowed action class;
- no use of the expected Einstein-Hilbert form as a derivational input;
- a stated uniqueness or non-uniqueness boundary.

### `POSTULATED_NATIVE_CANDIDATE`

Required:

- an explicit statement that the action is a new postulate rather than a
  derivation;
- complete mathematical specification and falsifiable recovery obligations;
- no claim that project principles forced the choice.

### `SUPPLIED_STANDARD_PHYSICS_BASELINE`

Required when the proposal is standard Einstein-Hilbert gravity, a known
standard modification, or an imported textbook action without an independent
project derivation or newly selected postulate.

Formula identity does not determine provenance. Merely renaming the
Einstein-Hilbert action does not make it ToE-native.

## 5. Minimal field and domain contract

The bounded first route selects only the metric field as the gravitational
variable:

`g_{mu nu}` on a four-dimensional, orientable, time-orientable Lorentzian
manifold `M` with retained signature `(+,-,-,-)` and `x^0=ct` in compatible
local coordinates.

The future proposal must state:

- metric regularity and admissible configuration space;
- whether variation is parameterized by `delta g^{mu nu}` or
  `delta g_{mu nu}`, with the conversion rule fixed;
- connection and curvature conventions;
- integration domain and volume orientation;
- whether the proposal is local or explicitly nonlocal.

The bounded default is a local metric theory. A nonlocal proposal fails this
route unless separately selected.

Excluded from this first sector contract:

- tetrads, independent spin connections, and full Dirac geometry;
- CCFT and statistical dynamics;
- Rep32 fields or operators;
- `C_k` multipliers or penalties;
- a successor master action;
- gravitomagnetic or orbital calculations.

Future spinor coupling remains a later matter-sector obligation. It is not a
reason to import tetrad machinery into the pure minimal gravitational route.

## 6. Symmetry contract

Any candidate must explicitly declare and demonstrate at the action level:

- diffeomorphism covariance;
- coordinate independence of the scalar action;
- locality for the selected bounded route;
- parity and time-reversal behavior;
- any additional proposed native symmetry;

Covariant-looking notation is not evidence that a symmetry holds.

The baseline route requires a parity-even and time-reversal-even pure metric
sector. Any symmetry-breaking term requires a new bounded theory selection.
