## Derivation-Grade Standard

A result counts as derivational only when it supplies:
- starting assumptions,
- mathematical object definitions,
- variational or dynamical equation,
- regime or limit map,
- equivalence or approximation theorem,
- explicit residual/error term when approximate,
- proof or mechanically checked formal counterpart.

A result does not count as derivational if it only supplies:
- artifact presence,
- schema consistency,
- status alignment,
- scaffold tokens,
- assumption-preserving restatement,
- publication or submission readiness.
