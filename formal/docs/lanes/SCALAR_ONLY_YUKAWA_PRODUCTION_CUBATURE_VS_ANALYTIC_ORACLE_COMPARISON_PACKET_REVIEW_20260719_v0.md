## Principal blocker: historical path identity

The original Stage A function is:

```text
reduced_four_dimensional_density_integral_yukawa_energy
```

It uses fixed equal radii and sequential outer accumulation:

```text
total = 0.0
...
total += block
```

The parameterized mirror defaults to block-list NumPy pairwise accumulation and
supports unequal radii:

```text
summation = PAIRWISE
newton_blocks / yukawa_blocks
np.sum(block_array)
```

The mirror is a reasonable diagnostic implementation, but it is not the same
frozen algorithm or physical input domain as the historical Stage A function.

The packet names a legacy-equivalence control, but it does not freeze:

- whether the historical lane must use the mirror's available `ORDINARY` mode;
- the exact legacy cases and orders used by that control;
- bitwise or numerical equivalence tolerance;
- the consequence of equivalence failure;
- which unequal-radius mirror results may support claims about the historical
  production calculator.

Without these rules, a comparison could diagnose the mirror while reporting a
conclusion about the old calculator.
