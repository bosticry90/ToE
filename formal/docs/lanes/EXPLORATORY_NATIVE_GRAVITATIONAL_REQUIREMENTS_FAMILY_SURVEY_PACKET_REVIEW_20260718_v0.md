## Review answer

The packet safely supports one faster, transparent exploratory investigation.
It does not create an alternate action selector.

Independent inspection confirms that the preparation generator imports only
standard-library modules. It has no scientific evaluator, survivor reducer,
equivalence reducer, terminal classifier, standard-GR-collapse branch, theory
recommendation function, or V2 matrix writer.

The canonical form inventory is exactly:

```text
requirements: 10
comparison families: 7
blank forms: 70
NOT_SURVEYED forms: 70
UNRESOLVED judgments: 0
all provisional judgments: 0
authoritative matrix cells: 0 / 70
```

The eight decision-critical questions are distinct, refer only to the frozen
requirements and families, remain unanswered, and are scheduled before any
cell-completion work. All seventy cells are explicitly optional.

The packet is accepted with the binding manual structural rubric below. The
rubric checks whether a provisional entry exposes its reasoning; it does not
judge whether the reasoning is scientifically correct. Scientific assessment
remains human and provisional.

## Review gate 1: no alternate selector

Pass.

No provisional label feeds a survivor count, equivalence class, native
selection, standard-GR collapse, no-go result, or action recommendation. The
form schema excludes V2 evidence IDs, claim scopes, cell statuses, scientific
outcomes, survivor sets, and equivalence-class fields.

Pattern summaries are permitted only in prose and only with exploratory
language. They may not be formatted as one of the six closed V2 outcomes.

## Review gate 2: blank and unresolved states are disjoint

Pass.

The binding interpretation is:

```text
NOT_SURVEYED
= no exploratory assessment was attempted
= provisional classification is absent
= reasoning fields remain blank

UNRESOLVED
= the relationship was examined
= provisional classification is UNRESOLVED
= rationale, assumptions, basis, uncertainty, and resolving work are present
```

A partially filled blank entry is neither state. It is
`INCOMPLETE_SURVEY_ENTRY` and must fail the independent result review.

## Review gate 3: nonblank entries must expose reasoning

Pass with a binding structural-completeness rubric.

A surveyed row must use workflow state `SURVEYED_PROVISIONAL`, contain exactly
one of the six provisional labels, and provide nonempty content for:

- concise rationale;
- assumptions and domain;
- source/derivation pointer or explicit absence marker;
- main uncertainty;
- resolving calculation, theorem, counterexample, or explicit statement that
  no further resolving work has been identified;
- manual adjudicator identity;
- manual review status.

Any nonblank classification missing one of these elements is
`INCOMPLETE_SURVEY_ENTRY`. It may not be counted, summarized, converted to
`UNRESOLVED`, or used in the opportunity map.

This is a structural review rule, not a scientific relevance validator. It
cannot promote a label or certify a rationale.

## Review gate 4: sources support only limited judgments

Pass.

The packet explicitly prohibits treating a special parameter value, special
model, recovery limit, or representative as evidence for a complete family.
Every source or derivation pointer must carry a scope note explaining the exact
requirement/family relationship it bears on.

Where a pointer supports only a subfamily or parameter domain, the provisional
entry must narrow its rationale to that domain or use `UNRESOLVED` for the
whole-family question.

## Review gate 5: reasoning basis and confidence are separate

Pass with a binding recording convention.

Each surveyed entry must identify at least one reasoning-basis type inside its
existing `source_or_derivation_pointers` field:

```text
ESTABLISHED_LITERATURE
DIRECT_MATHEMATICAL_REASONING
KNOWN_COMPARATOR_BEHAVIOR
ANALOGY
PROJECT_HYPOTHESIS
EXPERT_JUDGMENT
```

Each basis record must also state its pointer role, reference or explicit
absence marker, and scope note. A high-confidence provisional label does not
upgrade a weak basis, and a prestigious source does not select the label by
itself.

This convention uses the packet's existing field and does not change the blank
70-form schema.

## Review gate 6: decision-critical questions control work order

Pass.

The eight questions can materially affect research direction by testing:

- whether covariance and Newtonian recovery are nonselective;
- whether source coupling, momentum response, or stability distinguish the
  primary metric families;
- whether the `C_k` firewall constrains dynamics or only architecture;
- whether any accepted ToE-specific seam constrains the gravitational
  Lagrangian;
- whether property-scoped equivalence changes any comparison.

Phase 1 must address the eight question records before Phase 2 fills supporting
cells. The survey result must rank the next calculations or theorems by expected
information gain. Descriptive completeness does not receive priority merely
because a blank form exists.

## Review gate 7: the family envelope remains comparative

Pass.

All seven catalog rows retain `comparison_only: true`. The envelope is a
bounded instrument for testing current selection power, not an exhaustive
classification of gravitational theories.

The authorized survey may record that an omitted family would materially alter
a decision-critical question. It may not expand the family envelope during this
execution. Expansion would require a new target after result review.

## Review gate 8: V2 firewall remains closed

Pass.

The packet reads the frozen V2 JSON catalog snapshot for names and provenance;
it does not import or call `evaluate_analysis_v2`. Survey labels are not V2
statuses, survey records are not V2 evidence records, and the survey result may
not populate the closed V2 matrix.

```text
exploratory survey judgment
!=
V2 evidence cell
```

Any future authoritative use would require a fresh target and independent
scientific adjudication. This review does not authorize such a target.

## Bound execution protocol

Exactly one manual exploratory survey is authorized after this acceptance.

### Phase 1: decision-critical questions

For each of the eight questions, the survey must identify implicated
requirements and families, write the provisional analysis, state the main
unknown, and name the next decisive calculation, theorem, source review, or
counterexample.

### Phase 2: supporting cells only

The survey may fill only cells needed to support the question-level analysis.
Every other cell remains `NOT_SURVEYED`. There is no completeness quota.

### Phase 3: scientific opportunity map

The result must identify:

- high-confidence but apparently nonselective requirements;
- requirements with plausible discriminatory power;
- families requiring deeper analysis;
- critical unknowns and literature disputes;
- the best next bounded derivation;
- the best potential no-go or counterexample test;
- the likely location, if any, where a new native principle would matter.

Then it must stop for independent result review.
