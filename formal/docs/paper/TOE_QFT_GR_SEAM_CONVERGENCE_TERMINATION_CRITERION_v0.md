## Fixed End States

Allowed program outcomes:
- seam_discharged: only if bounded seam objective is satisfied under non-claim scope and no unresolved discriminator gap remains.
- seam_held: only if scalar/publication or bounded-scope governance conditions block justified continuation.
- seam_forked: only if remaining work is no longer productive within the current seam lane but remains research-relevant elsewhere.
- seam_terminated_as_nonproductive: only if marginal packet gain falls below threshold and no justified successor discriminator remains.

Disallowed outcome:
- indefinite_packet_extension_without_measurable_seam_level_gain

## Seam-Level Progress Metric

Every future authorization must justify seam-level progress across all of these dimensions:
- discriminator_strength_increase: successor discriminator must add new bounded discriminative content beyond the predecessor packet.
- residual_ambiguity_decrease: residual ambiguity at the active seam handoff must be explicitly reduced, not merely restated.
- remaining_gap_narrowing: unresolved admissible seam gap must become narrower relative to the reactivation objective, not only relative to the previous packet.
- objective_distance_reduction: the remaining distance to the bounded reactivation objective must decrease in a way that is explicitly stated and reviewable.

## Marginal-Gain Threshold

Minimum authorization requirement for any future packet:
- future_packet_must_exceed_local_narrowing_only: PASS_REQUIRED_v0
- future_packet_must_improve_seam_level_closure_prospects: PASS_REQUIRED_v0
- future_packet_must_state_expected_incremental_gain_in_one_sentence: PASS_REQUIRED_v0
- future_packet_must_not_be_justified_by_packet_order_alone: PASS_REQUIRED_v0

## Stagnation Test

Stagnation is triggered if any of the following holds:
- semantic_reencoding_without_new_discriminator_content
- negligible_residual_ambiguity_reduction
- no explicit reduction in remaining_objective_distance
- decision_equivalent_successor_where_authorization_and_hold_have_same_effective_information_content

Stagnation result:
- stagnation_result_status: HOLD_FORK_OR_TERMINATE_REQUIRED_v0

## Anti-Infinite-Ladder Rule

- anti_infinite_ladder_rule: a future packet cannot be authorized merely because it is narrower than the previous packet; it must also improve seam-level closure prospects under the active objective.
- local_progress_is_necessary_but_not_sufficient: ENFORCED_v0
- narrative_momentum_authorization: FORBIDDEN_v0

## Mandatory Disposition Rule

If convergence binding fails, the only allowed outcomes are:
- disposition_hold
- disposition_fork
- disposition_terminate

Forbidden disposition:
- authorize_next_packet_without_convergence_pass
